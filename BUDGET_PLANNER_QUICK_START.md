# Quick Start Guide - Budget Planner Feature

## How to Access

### From Home Page
1. Go to homepage at `/`
2. Scroll to "Confused about your budget?" section
3. Click **"Plan My Budget Now"** button (if logged in)
4. Or click **"Register & Start Planning"** if not logged in

### From Services Page
1. Go to browse services at `/services`
2. At the top of the page, you'll see a gradient banner
3. Click **"🎯 Plan My Budget"** button
4. Fill in your budget and explore suggestions

### Direct URL
- Paste this in browser: `/budget-planner`
- Must be logged in to access

---

## Step-by-Step Usage

### Step 1: Enter Your Budget
```
💰 Input: Total Budget (RWF)
Example: 5,000,000 RWF for a complete wedding
```

### Step 2: Get Suggestions
```
Click "🎯 Get Suggestions" button
- Analyzes your budget
- Suggests 4 package options
- Shows service breakdown
```

### Step 3: Review Budget Overview
```
See at a glance:
- Total Budget: Your input amount
- Total Allocated: System recommended spend
- Remaining: Extra budget or savings
```

### Step 4: Select a Package
```
Choose from:
📦 Economy (from RWF 1,500,000)
   - Venue, Catering, Photography

📦 Standard (from RWF 3,500,000)
   - + Decoration, Music/Entertainment

📦 Premium (from RWF 8,000,000)
   - All 10 service categories included

📦 Deluxe (Full Budget)
   - Premium vendors + Extras
```

### Step 5: Review Services
```
See services suggested for each category:
- Category name
- Suggested budget allocation
- Available services with prices
```

### Step 6: Auto-Book or Manual Select
```
Two Options:

✅ Auto-Book: 
   - Confirms your selected package
   - Books all suggested services
   - Redirects to dashboard

👤 Manual Booking:
   - Back button returns to services
   - Browse and select individually
```

## Troubleshooting

### "Page not found" when accessing budget planner
- **Fix**: Make sure you're logged in
- **URL**: Should be `/budget-planner` (not `/budget_planner`)

### Suggestions not loading
- **Fix**: Refresh page (Ctrl+F5 or Cmd+Shift+R)
- **Note**: JavaScript must be enabled

### Budget validation error
- **Fix**: Enter amount ≥ 100,000 RWF
- **Format**: Numbers only (no commas or special characters)

### Auto-booking shows error
- **Fix**: Try selecting a specific package first
- **Contact**: Support if issue persists

## Tips & Tricks

💡 **Maximize Your Budget**
- Start with the largest budget amount you can afford
- System suggests smartest allocation
- You can still customize after suggestions

💡 **Compare Packages**
- Review all 4 options before deciding
- Check "Services by Category" section
- Look for best value match to your needs

💡 **Manual Control**
- Don't like suggestions? Use "Manual Booking"
- Browse and select services individually
- No pressure to auto-book

💡 **Save Time**
- Auto-book takes 30 seconds
- Pre-made packages save research time
- Can modify bookings in dashboard
